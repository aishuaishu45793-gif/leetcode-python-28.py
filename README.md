## 💡 Example Problem

### Find the Largest Number

Given a list of numbers, find the largest number without directly using the `max()` function.

```python
numbers = [12, 45, 7, 89, 23]

largest = numbers[0]

for number in numbers:
    if number > largest:
        largest = number

print("Largest:", largest)
```

### Output

```text
Largest: 89
```
